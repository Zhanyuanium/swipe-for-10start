# mods/

start-menu-legacy-swipe.wh.cpp: the shipping mod, `StartMenuExperienceHost.exe`. Raw HID touch/pen decode (RIDI_PREPARSEDDATA + HidP_GetUsageValue), axis-aware state machines on a worker thread for both dismiss (drag inside the menu) and reveal (edge swipe; anchored to the panel trailing edge), `Progress` composition expression, dismissal by `VK_LWIN` tap after a one 260 ms retract curve, shortened only by flick velocity. The release is detected by an 18 ms silence measured with `QueryPerformanceCounter` on a 5 ms `CREATE_WAITABLE_TIMER_HIGH_RESOLUTION` idle tick (`WM_TIMER` ignores the 1 ms `timeBeginPeriod` request on this build). Hooks `StartUI::App::PrepareRootElement` (hardcoded RVA) for the root and an experimental `SplitViewFrame::OnGlobalAnimationRequested` hook (`anim=` debug switch, off by default because that request also presents the panel). The debug channel also takes `retract`, which plays the close animation on request; a `retract` inside 600 ms of a gesture close is dropped, and a new edge pull stamps `hide-abort.txt` so the explorer-side hide is cancelled.
msgprobe.wh.cpp: diagnostic. Hooks `GetMessageW`/`PeekMessageW`, logs `WM_POINTER*` and mouse messages. Established that the queue carries only ENTER + DOWN and then `WM_POINTERCAPTURECHANGED`.
inputprobe.wh.cpp: diagnostic. Raw HID listener plus a `CoreWindow`/`SystemUserAdapterWindowClass` WndProc subclass. Took the digitizer stream first and proved per-frame reports are readable. Must not run beside the shipping mod: Raw Input allows one sink per usage per process.
start-menu-touch-gesture-bridge.wh.cpp: `explorer.exe` bridge. Hooks `CStartExperienceManager::Hide` (`HRESULT (void*, uint32_t)`, RVA `0x3C5960`) and waits up to 350 ms in 10 ms polls after writing `retract=1` to the Start mod's `debug.txt`, which turns a Windows-key close into a slide-out; a newer `hide-abort.txt` stamp from a new edge pull makes it log `hide aborted` and return `S_OK` without the original. Publishes the taskbar edge gesture handle and state from `twinui.pcshell.dll` into shared memory (not read by the shipping mod); refuses to hook on a build mismatch.
start-menu-touch-gesture-probe.wh.cpp: Phase 0 probe that located `TouchEdgeGestureProcessor` and `ReportEdgeGesture`.
start_gesture_shared.h: shared-memory contract shared by the bridge and its consumer; layout must stay in sync with both.
