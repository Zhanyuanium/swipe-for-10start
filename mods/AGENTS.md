start-menu-legacy-swipe.wh.cpp: the shipping mod, `StartMenuExperienceHost.exe`. Raw HID touch/pen decode (RIDI_PREPARSEDDATA + HidP_GetUsageValue), axis-aware state machines on a worker thread for both dismiss (drag inside the menu) and reveal (edge swipe; anchored to the panel trailing edge), `Progress` composition expression, dismissal by playing one damped-spring settle and then tapping `VK_LWIN` (down 60 ms, up) at the end of it; that tap is the shell's own Start toggle, so its key handler performs `CStartExperienceManager::Hide` and the next Windows press opens. One spring generator serves all four gesture outcomes and the keyboard open; `AnimationStyle` picks only its damping: `Windows 11` (default) 1.72, fitted to the native Quick Settings flyout on this machine, and `Windows 10` 0.9. Both start at `GestureStartSpeedPercent` (default 100) of the finger's release speed over the travel left, so a release from a hold starts at zero speed and a flick continues; the duration is that travel at the flyout's 2.2 DIP/ms, clamped to 160-520 ms (409 ms for the 900 DIP panel, 520 ms for the 1440 DIP travel of this machine's left taskbar), and the frequency is derived so five time constants of the spring's slowest root land on it. The samples are scaled by the curve's own value at `T`, so the 0.7% those time constants leave short spreads over the animation and the final frame is exact with no step. One curve serves every open and close: a keyboard open is that settle from rest (`vel=0.00`), so a Win press and an edge pull cannot look different. At the release the mod stamps the close channel with the gesture kind; the tap is armed for the end of the settle, and one pull-generation check drops it (the stamp then says cancelled) if a new pull began first. No request file, no bridge-hide worker, no re-arm tap. The release is detected by an 18 ms silence measured with `QueryPerformanceCounter` on a 5 ms `CREATE_WAITABLE_TIMER_HIGH_RESOLUTION` idle tick (`WM_TIMER` ignores the 1 ms `timeBeginPeriod` request on this build). Hooks `StartUI::App::PrepareRootElement` (hardcoded RVA) for the root and an experimental `SplitViewFrame::OnGlobalAnimationRequested` hook (`anim=` debug switch, off by default because that request also presents the panel). The 600 ms post-close suppression ends at `win close observed`, so a Win press after the hide opens a visible panel. The channel (`swipe_ipc_shared.h`) is one session-local section plus three events: the command event carries `p`/`t`/`e`/`anim` from `tools/ipc.ps1`, the retract request event carries the bridge's keyboard-close request, and this mod answers it with the duration it just planned (or the no-settle sentinel) under the request's sequence number. The files the earlier builds polled (`debug.txt`, `close-mode.txt`, `retract-plan.txt`) are deleted at init.
msgprobe.wh.cpp: diagnostic. Hooks `GetMessageW`/`PeekMessageW`, logs `WM_POINTER*` and mouse messages. Established that the queue carries only ENTER + DOWN and then `WM_POINTERCAPTURECHANGED`.
inputprobe.wh.cpp: diagnostic. Raw HID listener plus a `CoreWindow`/`SystemUserAdapterWindowClass` WndProc subclass. Took the digitizer stream first and proved per-frame reports are readable. Must not run beside the shipping mod: Raw Input allows one sink per usage per process.
start-menu-touch-gesture-bridge.wh.cpp: `explorer.exe` bridge. Hooks `CStartExperienceManager::Show/Hide` (`Hide` is `HRESULT (void*, uint32_t)`, RVA `0x3C5960`). A Hide on an unconsumed close stamp inside its 800 ms window is the Start side's own tap, sent after its retract, so it runs at once (`hide passed (gesture)`); a cancelled stamp, a stale stamp, or a second Hide under the same stamp is a keyboard close: the bridge publishes the `retract` request on the shared channel, waits up to 100 ms on the plan event for the Start mod's answer (echoed under the request's sequence number), then holds the original synchronously for that answered settle plus 30 ms (`hide delayed reason=... retract=520 lead=550` on this machine), or for a fixed 560 ms when no answer arrives. No worker, manager pointer, timer, dispatch window or re-arm tap remains; every path calls the original. Publishes the taskbar edge gesture handle and state from `twinui.pcshell.dll` into shared memory (not read by the shipping mod); refuses to hook on a build mismatch.
start-menu-touch-gesture-probe.wh.cpp: Phase 0 probe that located `TouchEdgeGestureProcessor` and `ReportEdgeGesture`.
start_gesture_shared.h: shared-memory contract shared by the bridge and its consumer; layout must stay in sync with both.
